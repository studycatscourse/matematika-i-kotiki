# математика и котики — вероятность

Статический учебный сайт для GitHub Pages.

## Публикация
1. Загрузите `index.html`, папку `materials/` и `README.md` в корень GitHub-репозитория.
2. В репозитории откройте **Settings → Pages**.
3. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Дождитесь публикации сайта по адресу GitHub Pages.

Все ссылки на видео и Telegram уже указаны в `index.html`. Тестов и материалов по другим предметам в этой версии нет.

Логотип встроен прямо в `index.html`, поэтому он отображается даже при открытии HTML-файла отдельно. Для публикации можно загрузить `index.html` и папку `materials/`; папка `assets/` больше не обязательна.
